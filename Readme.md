🚓 Verificador de Multa por Excesso de Velocidade – Python
Este script simples em Python simula um radar de velocidade. Se o motorista ultrapassar o limite de 80 km/h, uma multa é aplicada automaticamente. Um ótimo exercício para praticar condicionais (if) e operações matemáticas.

🔧 Funcionalidades
Recebe a velocidade atual do carro como entrada

Verifica se o limite de 80 km/h foi excedido

Calcula a multa no valor de R$7,00 por km/h acima do limite

Exibe mensagens informativas ao motorista

📌 Exemplo de Uso

Qual a velocidade atual do carro? 75  
Tenha um bom dia! Dirija com segurança!  

Qual a velocidade atual do carro? 90  
MULTADO! Você excedeu o limite permitido que é de 80km/h  
O valor da multa é de: R$70.00  

Tenha um bom dia! Dirija com segurança!  

💡 Tecnologias Utilizadas
Python 3.x

Entrada de dados com input()

Condicional if

Operações matemáticas básicas

Formatação com format() para exibir valores em reais
